HL7 v2 Message Inspector

Structural preflight checks for a single ER7 message, including MSH, PID, OBR, and OBX. Works offline after loading; no backend is required.

Message input

Paste an HL7 v2 message or open a local text file (maximum 1 MiB). Use synthetic data for demonstrations.

Input remains in this browser tab. Nothing is sent to a server, uploaded, logged, or saved by this application. Do not interpret these limited checks as HIPAA Safe Harbor de-identification, standards certification, or clinical validation.
